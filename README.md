# 📊 E-Commerce Sales Analysis Dashboard

An interactive **E-Commerce Sales Analysis Dashboard** developed using Microsoft Excel to analyze sales performance and identify key business insights.

## Project Overview

This project presents an interactive Excel dashboard designed to analyze e-commerce sales data across different regions, customer segments, years, and product categories.

The dashboard allows users to interact with the data using filters and quickly understand sales trends and performance.

##  Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning & Analysis
- Data Visualization

## Dashboard Features

Region-wise Sales Analysis,
Segment-wise Analysis,
Year-wise Sales Analysis,
Category-wise Sales Analysis,
Top 5 Performance Analysis,
KPI Analysis,
Interactive filters using Excel Slicers,
Sales trend and performance visualization.

## Key Insights

The dashboard helps users:

- Compare sales performance across different regions.
- Analyze customer segments and their contribution to sales.
- Track sales performance across different years.
- Identify high-performing product categories.
- Monitor important sales KPIs.
- Make data-driven business decisions through interactive visualization.

##  How to Use

1. Download `Ecommerce_Sales_Dashboard.xlsx`.
2. Open the file using Microsoft Excel.
3. Navigate to the dashboard sheet.
4. Use the **Region, Segment, and Year slicers** to filter the data.
5. Explore the charts, KPIs, and sales insights.
